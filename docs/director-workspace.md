# 分鏡導演台與流程畫布整合

## 本版

同一畫布的兩個視圖，預設先開分鏡導演台。既有影片節點直接顯示為分鏡，不另建資料庫或複製專案。

- 故事原稿以文字節點保存；依空白段落新增分鏡。這是明確的段落切分，不是模型自動分析，不收取生成費用。
- 分鏡可命名、前後排序、複製、刪除、指定參考素材。
- 敘事、角色動作、運鏡、聲音、銜接備註組成實際影片請求的提示詞。
- 每鏡設定模型、解析度、秒數、畫幅；規格沿用現有模型目錄。
- 單鏡生成重用已完成的上游輸出，缺少的上游才執行。送出前按即時費率確認。
- 3D 構圖可從分鏡開啟，截圖保存後作為相連圖片參考。錄製片段尚未從此入口自動接成影片參考。
- 畫布與導演台共用既有版本衝突保護與儲存；仍須點選儲存。
- 修改生成參數只使該節點及後續相依結果失效，獨立分鏡結果保留。排序、位置、分鏡名稱不使成品失效。
- 分鏡時間軸展示規劃時長，不是影片剪輯或合成時間軸。

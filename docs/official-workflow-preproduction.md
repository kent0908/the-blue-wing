## 使用順序

1. 在流程畫布的「官方模板」複製一套，先讀最左側製作筆記。
2. 世界規則是人工可編輯筆記，沒有接入文字生成模型，也不會自動同步到每個提示詞；請一起修改。
3. 先檢查角色臉部、衣服、道具左右位置，再確認場景的門窗與光向。範例舊驛站與銅鈴不改寫藍翼角色正史。
4. 合成模板必須使用同一素材節點放三張圖：角色、場景、道具；檢查實際順序。角色卡用來鎖身份，場景卡鎖空間，道具卡鎖外形，不能直接把三視圖當影片首幀。
5. 圖片確認後再生成短鏡。既有執行器的單點執行包含上游，重跑會再調用；若要沿用已確認結果，存入素材庫並用素材節點替換原上游連線。全部執行不會自動在檢查點停止。
6. 三段短鏡需自行剪輯；檢查軸線、起始姿勢、動作終點、呼吸與停頓。這次不提供未驗證的成品示範影片。

## 模型與成本

圖片沿用平台現有 GPT Image 2.5 Sunburst、3840 × 2160；短鏡沿用既有 Seedance 2.0 mini、720p、5 秒，可在節點自行改為所需模型。沒有因為參考文件提到某模型就新增未確認的 API 參數。音訊描述是創作方向，實際能力依選用模型，無音訊時需後製。

複製模板只建立私人畫布，不調用生成 API。按執行前看畫布點數明細；此表是節點數，不是固定售價，也不含重試。未替使用者進行任何付費圖影生成。

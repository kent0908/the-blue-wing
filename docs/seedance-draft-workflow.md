# Seedance 2.5 草稿流程

目前狀態：僅介面預覽，尚未接入 SIRAYA。

入口：影片創作區選擇 SIRAYA-Seedance-2.5 →「即將開放 · 查看流程」。

流程：構思與草稿 → 播放與審看 → 正式成片。

目前只可切換流程說明；生成按鈕 disabled，沒有 API 呼叫、任務建立或扣點。原有正式生成維持不變。

## 待 SIRAYA 參數完成後

- 確認草稿建立、查詢與正式成片的實際 request/response，不預先假設 extra_body 的欄位。
- 確認支援規格、模型識別、素材限制、有效期限與兩階段計費；公開確認後的點數報價。
- 保存草稿原始設定快照、上游任務 ID、使用者所有權、狀態與有效期限，正式成片綁定來源草稿。
- 提交前由伺服器驗證所有權、期限與餘額；兩階段分開記帳，保留冪等提交與失敗退款。
- 處理草稿失敗、過期、成片失敗及重新整理後恢復；不要用草稿媒體下載網址代替上游任務 ID。
- 正式成片沿用現有作品儲存及下載流程，確認後再開放實際生成入口。

## 驗收

- 僅 Seedance 2.5 影片顯示入口。
- 三步可前後切換；Escape、關閉按鈕與背景點擊可關閉對話框。
- 小螢幕對話框可捲動，生成按鈕保持停用。
- 開啟預览不改動提示詞、素材及正式生成參數。
